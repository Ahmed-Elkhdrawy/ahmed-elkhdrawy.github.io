Privacy Policy

Animal Worlds Studio Uploader · Last updated: 31 October 2026

This policy explains how the Animal Worlds Studio Uploader ("the app") uses data from Google accounts. The app is a private tool operated by the owner of the Animal Worlds Studio YouTube channel, for that channel only.

Who uses the app

Only the channel owner signs in to the app. It is not offered to the public and has no other users.

What data the app accesses

With the owner's permission, through Google's OAuth sign-in, the app uses these YouTube permissions:

  • youtube.upload: to upload the owner's approved videos and set their thumbnails;
  • youtube.readonly: to confirm which channel is connected and check the status of uploaded videos;
  • yt-analytics.readonly: to read performance statistics for the channel's own videos.

The app does not access Gmail, contacts, Drive or any other Google data. It does not access other people's channels or data.

How the data is used

The data is used only to publish the owner's own videos and to show the owner how those videos perform. It is not sold, shared with third parties, or used for advertising. It is not used to train AI models.

Storage and security

The sign-in token is stored only on the owner's private server, in a file readable only by the app. Video records and statistics are kept in the owner's private database on that server. Nothing is stored by any third party on the app's behalf.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

The owner can revoke the app's access at any time at myaccount.google.com/permissions. When access is revoked, the stored token stops working and is deleted from the server. Statistics already collected are deleted on request.
